## Results

- 本次实际落地为 **1 个提交、35 files changed、+4838/−42**：新增 `templates/mobile/`（15 个模板、`mobile.css`／`game-mobile.css`、`mobile.js`／`image-fallback.js`、`mobile_helpers.inc.php`、`templates.lang.php`、`README.md`）与 `gamedata/tests/mobile_template_test.php`，并改动模板选择、切换入口与三个既有测试。
- **设备识别与模板解析**：`dts_is_mobile_client()` 识别 Android／iOS／iPadOS／HarmonyOS（含 ArkWeb）／Kindle／黑莓／Opera Mini／UC／QQ 浏览器／微信等 UA，并支持 `Sec-CH-UA-Mobile: ?1`；`dts_resolve_ui_template()` 按 `dts_ui_mode` Cookie、`?ui_mode=mobile|desktop`、账户 `u_templateid` 与设备类型决定模板。手机与平板（含未登录游客）首次访问默认进入移动版；账户原先选的是移动专版时，切回原版会落到经典界面，否则保留账户原本的桌面模板选择。
- **切换入口**：`dts_ui_mode` Cookie 有效期一年、路径 `/`；顶部导航新增「手机版」链接（经典与 Nouveau 各一处），`dtsSwitchUiMode()` 会清除 URL 上的 `ui_mode` 参数再跳转；`user.php` 开放 `u_templateid = 3`（MOBILE 移动专版），切换移动版时同步写 Cookie，切回桌面模板时写 desktop。顺带修正了 `Cookie.deleteCookie` 未带 `path=/` 导致清不掉同名 Cookie 的旧问题。
- **iPadOS 桌面 UA**：`classic.js` 与 `nouveau.js` 在 `maxTouchPoints > 1` 且 UA 含 Macintosh、且未手动选择界面时，写一次 `dts_ui_mode=mobile` 并刷新，用 `sessionStorage` 防循环。
- **移动界面**：`< 900px` 为底部四栏拇指坞（行动／状态·装备／地图／通讯）+ 常驻 HUD（地点、禁区状态、天气、HP／SP／怒气／歌魂、包扎按钮、技能与任务入口），平板 `>= 900px` 为左右双栏；遭遇战、尸体与雷达在行动视图展开。导航抽屉覆盖全站入口，6 套 Dark Aero 预设与自定义配色；未移植的邮件、成就、后台等页面按 `template()` 回退到 default 自适应显示。大房间 PvE 所需的称号选择、姿态／策略／视界、换武器与卸装、背包使用／合成／元素口袋、地图点选移动（含 `pgroup=3` 湾城投影与 `pgroup=4` 英灵殿）、中枢控制台、七日送行与对白分支均在移动模板内实现。

## Limitations and Follow-up

- 本机无 MySQL，未启动站点、未做 HTTP 联调，也没有实体手机／平板浏览器验证；触控手感、滚动、误触、横竖屏切换与移动端性能均未实测。以上为模板编译、选段渲染与脚本级检查。
- 移动版依赖 UA／Client Hints 判断；UA 被改写、隐私浏览器或代理可能误判。iPadOS 桌面 UA 依赖 default／nouveau 页面里的 JS 首跳，若首个入口本身不是这两套模板（例如直接进入移动版）则不需要该逻辑。
- 自动识别会让手机／平板默认落在移动版，偏好桌面的玩家需要手动切一次「原版界面」，该选择存在一年期 Cookie 中；清 Cookie 后会重新按设备判断。
- 移动模板只移植了主站导航与局内主流程，邮件、成就、后台等仍回退 default，视觉与触控一致性以 default 为准；README 已注明这一边界。
- 静态资源带 `?v=20261119` 版本号，未验证 CDN／反向代理缓存与旧缓存淘汰；上线后如需强制刷新需改版本号。
- 本轮未修改游戏工作区，未部署公测服，未改动任何账户数据；知识仓库只新增本日志与 INDEX 一行。
