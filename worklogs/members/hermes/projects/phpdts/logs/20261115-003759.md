## Limitations and Follow-up

- 本机无 MySQL，未启动站点、未做 HTTP/真实数据库联调。以上是假数据库桩、纯函数调用与模板编译结果；作者提交记录中的 PHP 7.4.33、一次性 MySQL 5.7.44、双进程并发、真实 `command.php` 合成/使用与浏览器两套界面验证均为其自述，本轮未独立复现。
- 侧栏 QUEST 标签的展开、AJAX 刷新与重载后恢复只有模板编译与 `sendo_tracking()` 数据层的自动断言；渲染后的实际显示效果依赖作者浏览器验证，本轮没有浏览器级断言。
- 开局常驻以新局初始化为准：更新前已经在跑的局不会补生成七名 type 36，需等下一次开局；历史漏发的成就同样不会随代码更新自动补登（与实装记录的「范围」一致）。
- `sendo_sync_hubs()` 在每次操作、每次 tick 与每次任务指令后都会执行，需要查询存活玩家进度、存活猎手与全部 type 36 行；本机未做玩家规模下的性能测量，玩家数大时是线性成本，可作为后续观察点。
- 本轮未修改游戏工作区，未部署公测服，未改动任何账户数据；知识仓库只新增本日志与 INDEX 一行。
