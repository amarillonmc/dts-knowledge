## Results

- **描述拆分（ef815cc）**：`ending_skills_1.php` 中 37 个可获得技能的数据由 `array(名称, 描述)` 改为 `array(名称, 玩家描述, NPC 描述)`；合并循环 `ending_skills_1.php:60` 仅在有第三项时写入 `$cskills[$id]['ndesc']`。`parse_skilldesc()` 改为 `empty($data['type'])` 时取 `desc`、否则取 `ndesc`，`ndesc` 缺失或为空回退 `desc`；`bdesc` 优先级与标签、等级、参数替换逻辑未动。NPC 专属技能保持原样，技能 ID 全部不变。
- **文案同步**：37 个技能统一改为两字简称（如「荣拳」「解析」），另将「跨维度窃盗」缩为「维度窃盗」；描述按现有实现校准了概率与体力消耗。实测玩家侧「命中时有30%概率耗30体力，使伤害提高25%」、NPC 侧「把尚有余力的对手打至生命底线，交战越久底线越高」；无 `ndesc` 的 `npc_retro_barrier` 两侧同文（玩家无法获得，符合预期）。
- **等级字段（464ad8b）**：历史残响预设 1303 级在两处被截断——`players.lvl` 原 `tinyint unsigned` 入库变 255；`lvlup_rev()` 首次经验结算也把 NPC 压回 255。新局 DDL 改 `smallint unsigned`，经验结算仅对玩家保留 255 封顶。该表由新局重建生效，不对旧局手工迁移。
- **AI 分体计数**：`valid.php` 补 `game.func.php` 依赖（首次创建分体 500）；`save_gameinfo()` 在结局路线下按主账号统计参战/存活，跳过 `ai_master` 分体行，旧规则集保留原口径。
- **胜者字段**：`winners.name` 归档改存实际账号名（`$winner_account`），`game.winner` 保留机体名并把 `game.winner` 列由 `char(15)` 扩到 `char(40)`；`roommng_verify_db_game_structure()` 用既有创建锁＋二次确认做幂等迁移，`install/bra.sql` 同步。
- **战斗与界面修复**：协战击破湾城阶段 BOSS 时，加时同时更新 `$GLOBALS['pdata']` 引用，避免指令末尾保存覆盖；瞬刃改为「位置变化或自身攻击」才加残影（原实现每次交锋准备无条件加，原地不动也能叠），并同步说明；`quest_sendo` 模板补 `$plsinfo` 与 `$pdata`；nouveau 游戏页补 `CURSCRIPT`，恢复公共 AJAX 背景逻辑。
- 两个 commit 共 22 + 3 个文件；`ending_skills_1.php` 的 NPC 侧文案同时修正了残影「NPC移动或攻击留下残影」等与实现不一致的旧描述。

## Limitations and Follow-up

- 本机无 MySQL：真库部分（install.php 新局、四进程 process.lock、players.lvl/winners.name 迁移、AI 分体与湾城全链路）为实装作者在隔离 MySQL 5.7.44 + 四个 PHP HTTP 进程上的自述结果，本轮只验证语法、桩级回归与模板编译，未复跑真库。
